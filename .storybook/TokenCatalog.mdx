# Design token catalog

This preview is generated from `packages/lyra-ui/tokens/canonical-tokens.json`, the same authored
source that produces the CSS fixture, editor/docs inputs, and DTCG interchange file. It does not
parse component TypeScript or maintain a second list of token names.

Consumers can import the interchange document from
`@aceshooting/lyra-ui/design-tokens.json`. The generated
`@aceshooting/lyra-ui/design-tokens.css` entry exposes explicit `.lr-token-light` /
`[data-lr-design-token-mode="light"]` and dark fixture selectors for previews and design-tool
validation; use `@aceshooting/lyra-ui/theme.css` for the production theme.

The values below are machine-generated reference data, not a human visual-approval record. Use the
light/dark toolbar and component stories for rendered behavior; human baseline review remains a
separate qualification state.
