## Delivery order and qualification

1. Establish discriminating regressions for SEC-01 and MAP-01, then implement and review each
   correction independently. Complete the bounded publication/localization copy corrections.
2. Capture performance baselines and structural counters before optimization. Address map
   preflight behavior with PERF-03, then consolidate its runtime under CLEAN-04 without mixing
   the separately owned style-readiness correction into that change.
3. Address sparse GPU state work and resumable fallback scheduling as separate changes with
   real-GPU interaction and unavailable-worker evidence. Specify compatible asynchronous model
   loading before changing synchronous contracts; share lower-allocation XYZ ingestion and
   per-format parser boundaries with worker routing. Qualify stable map-anchor placement separately
   from object-style readiness. Evaluate document query optimization within lyra-docs releases.
4. Perform the selected consolidations in bounded changes. Freeze coverage policy fixtures before
   CLEAN-01 and syntax/metadata fixtures before CLEAN-06; preserve the existing behavioral suites
   for hierarchy, chart and label helpers.
5. Regenerate artifacts from authored sources, measure package/bundle costs, and qualify the exact
   candidate with existing CI, three-engine component coverage, full browser workflows and
   Quality tools including the A/B benchmark. Changed companions require their own packed/runtime
   gates. Budget changes require explicit review and approval; preserve admission, accessibility, localization
   and coverage policy.

No wholesale source split, dead-code deletion or dependency removal is justified by this review.
A deletion needs its own reachability and contract evidence. Existing Knip, architecture and
metadata freshness gates remain authoritative.
