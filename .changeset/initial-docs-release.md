Publish the first public experimental DOCX editor companion. It provides `<lr-docx-editor>` and `createDocxSession` for local DOCX editing, bounded text, table, and image actions, and explicit save receipts with host acknowledgement. The document engine remains an optional, lazy-loaded peer. See the README for supported inputs and limits; general Word compatibility is not promised.
