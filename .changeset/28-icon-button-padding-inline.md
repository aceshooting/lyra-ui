`<lr-icon-button>` documents `--lr-icon-button-padding-inline` (default `0`), the logical inline padding of its native control. A trigger that shows a short text value such as `€ EUR` no longer needs a `::part(button)` rule for breathing room. The default keeps an icon-only button at exactly its `--lr-icon-button-size` hit-area floor, which still applies with padding set.
