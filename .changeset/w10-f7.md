- `lr-map` keeps its native map, camera, markers, controls, custom layers, camera session and scene renderer across a same-task DOM move (`moveBefore()`, or remove and re-insert in one task). A genuine disconnect still releases everything, one microtask later instead of synchronously; camera sessions and custom layers report `disconnect`/`removed` at that point. While detached, `project()`, `unproject()` and `editDrawing()` return their unavailable result. Migration: code that removed a map and re-inserted it in the same task to force a new native map must now let a microtask pass between the two (or replace the element); code that inspected teardown right after `remove()` must await a microtask.
- `lr-map`: a reconnected map's `scene` no longer reports and announces the previous connection's initialization failure before the new connection settles.
