`lr-markdown` and `lr-markdown-core` add `--lr-markdown-heading-margin-block-start` (the space before a heading; `--lr-markdown-block-gap` stays the space after every block) and `--lr-markdown-code-block-font-size` / `--lr-markdown-code-block-line-height` for fenced code. Each defaults to the current value.
