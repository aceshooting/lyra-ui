Preserve newer data-grid collection assignments when reading an older caller-owned array reenters a setter. Data, columns, column order, grouping, page-size choices and expanded keys now retain the latest snapshot. Selected rows and key aliases share assignment ownership, including initial template bindings, and row admission metadata stays paired with the data it describes.

The guards add 1,504 runtime/declaration bytes to the unchanged package inventory and 1,002 raw bytes to the packed core bundle. Only exceeded package and aggregate bundle ceilings advance to their next 64-byte boundaries after measurement.
