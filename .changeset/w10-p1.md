- `lr-data-grid`: assigning a large flat `data` collection is faster again. The row projection and display list no longer allocate a traversal record per row or consult the child-row cache when `childRows` is unset, the root rows reuse the projection when nothing was skipped, and a measurement reset with no measured rows no longer re-indexes every row offset only to discard the anchor.
- The shared measured-offset index used by `lr-data-grid` and `lr-virtual-list` clamps a full height reset in one pass.
