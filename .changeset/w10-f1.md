- The viewers family barrel (`@aceshooting/lyra-ui/components/viewers`) no longer exports the `LyraGeojsonView` subclass. Import `LyraGeoJsonViewer` instead; `lyra-ui-migrate --origin=lyra-v31` re-binds `import { LyraGeojsonView } from '@aceshooting/lyra-ui/components/viewers'` to `LyraGeoJsonViewer as LyraGeojsonView` and reports other uses.
- `adaptA2UiSurface()` results no longer carry the `state` alias of `bindingState`; read `bindingState`.
- Profile `export` globals in the migration ledger may now name a `./components/<family>` barrel as well as the package root.
