- `lr-chart` (and its typed presets), `lr-lite-chart`, `lr-box-plot`, `lr-chart-3d` and a provider-backed `lr-json-viewer` keep their chart runtime, renderer, prepared data and loaded tree across a same-task DOM move (`moveBefore()`, or remove and re-insert in one task). A genuine disconnect still releases them, one microtask later instead of synchronously. Migration: code that removed one of these elements and re-inserted it in the same task to force a rebuild must now let a microtask pass between the two (or replace the element).
- `lr-terminal`: setting `follow` to `true` directly now scrolls to the latest line at once, without emitting `lr-follow-change`.
- `lr-video`: a rejected playback request from the play/pause button, the poster play action or `togglePlay()` now emits `lr-render-error` (`detail: { error }`) and shows and announces the localized `error` part. An interrupted request (`AbortError`) is not reported.
- `lr-graph` and `lr-neighbor-list`: `updateComplete` now also covers the source pager's first render after its lazy registration.
