The package now bundles the agent skills and ships a `lyra-ui` executable. AI coding agents (Claude Code, Codex, OpenCode, Cursor, Gemini CLI, GitHub Copilot, Amp, Windsurf) run `npx lyra-ui init-agents` (add `--agent <name>` if not auto-detected) to install the `lyra-ui` and `compose-lyra-interfaces` skills for themselves; it prints the installed paths and the step that makes the agent load them (`--json` for a machine-readable result). The canonical copy goes to the shared `.agents/skills/` as symlinks into `node_modules` (so upgrades refresh them); agents that need their own directory (Claude Code: `.claude/skills/`) get a link to it. The invoking agent is detected from its documented environment (Claude Code, Gemini CLI), then project config; humans at a terminal are asked which agents to set up, and CI or agents get the detected defaults without a prompt. `--agents claude,opencode|all`, `--copy`, `--link`, `--dry-run`, `--force`, `--yes` and `--dir` are available. A marked `<!-- lyra-ui:start -->` block is added or refreshed in `AGENTS.md` (created if missing) and in `CLAUDE.md` (only if it exists and does not import `AGENTS.md`). It is idempotent, never edits content outside its own block or skill directories, and runs no postinstall. The bundled skills reference the package's own `llms/` directory; `lyra-ui migrate-wa` forwards to `lyra-ui-migrate`, which is unchanged.
